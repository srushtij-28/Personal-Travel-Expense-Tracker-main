# Personal Travel Expense Tracker

A Python command-line application to manage travel trips, record expenses,
track budgets, and view category-wise spending.

## Features

- Create travel trips
- View all trips
- Search trips by destination
- Add expenses to trips
- View trip expenses
- Filter expenses by category
- Update expense records
- Delete expense records
- Delete trips
- Calculate total trip expenses
- Compare expenses with trip budgets
- Display category-wise statistics
- Store data using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Date Handling
- Lists and Dictionaries
